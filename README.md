## Projects I'm Proud Of

  Built with TypeScript, Node.js, Express, MongoDB and LLMs.

- [**Evently**](https://github.com/DeepakJalumoori/Evently-Backend) — A RESTful event booking backend where
  organizers can create and manage events while attendees can discover
  and book them. Includes role-based authentication, event filtering,
  pagination, booking management and protection against overbooking
  using atomic updates and MongoDB transactions.

- [**DevTinder**](https://github.com/DeepakJalumoori/DevTinder-Backend) — A full-stack developer networking
  application built with React, Node.js, Express, MongoDB and WebSockets.
